# 서버 주소

## 구성

### Tab 1 – 이미지 생성 실습
| 등급 | 텍스트 이해 모델 | 이미지 생성 모델 |
|------|--------------|--------------|
| 🔵 하 | Phi-3.5-mini (3.8B) | SD v1.5 (512px) |
| 🟡 중 | Qwen2.5-7B | SDXL (1024px) |
| 🔴 상 | Qwen2.5-14B (4-bit) | FLUX.1-schnell (1024px) |

- 6가지 조합 중 선택 가능
- 한국어 입력 → LLM이 상세 영어 프롬프트로 확장 → 이미지 생성
- 확장된 프롬프트를 화면에 표시해 파이프라인 과정 시각화

### Tab 2 – LoRA 파인튜닝
- SD v1.5 (하 모델)에 커스텀 이미지-캡션으로 LoRA 학습
- 학습 전/후 비교로 파인튜닝 효과 직접 확인
- Loss 곡선 실시간 표시

### Tab 3 – 이론 설명
- VLM 파이프라인 다이어그램
- Diffusion Model 원리
- LoRA 설명

---

## 파인튜닝 사용법

1. **학습 데이터 추가**: 이미지 5~20장 업로드 + 캡션 작성
   - 캡션에 고유 트리거 단어 포함: `"a photo of sks character, smiling"`

2. **학습 실행**: 스텝 수 설정 후 학습 시작
   - 빠른 체험: 200 스텝
   - 권장: 500 스텝

3. **결과 확인**: "학습 전/후 비교" 섹션에서 같은 프롬프트로 Before/After 비교
